# Elvish

An ancient language that can be used in sacrifices, prayers, and spell casting. It can use the natural forces.

Every word is rich in meaning and the sentences are very short.

Elvish was created by the Elf King in the Sprouting Era. According to Elvin Legend, a first-generation elf is born with every word produced. The number of Elvish words meant the number of first-generation elves.
